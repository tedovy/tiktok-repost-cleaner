# TikTok Repost Cleaner

[English](README.md) · [Русский](README.ru.md) · [简体中文](README.zh-CN.md) · [العربية](README.ar.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · [Español](README.es.md) · [Português (BR)](README.pt-BR.md) · **日本語** · [한국어](README.ko.md) · [Türkçe](README.tr.md)

TikTok のリポストをワンクリックで削除するブラウザ拡張機能です。すべて、または最新のものだけを削除できます。

- **高速。** リポスト一覧を複数ページ同時に読み込み、数十件の並列リクエストで削除します。一覧の読み込み中から削除が始まります。
- **すべて、または最新 N 件。** 全部消すことも、削除する最新リポストの数を指定することもできます。
- **3 段階の速度：** 慎重・標準・高速。
- **TikTok のページ上でリアルタイムに進捗を表示：** カウンター、1 秒あたりの件数、停止ボタン。
- **11 言語対応。** ブラウザの言語に合わせて表示されます。
- **Chrome、Edge、Brave、Opera、Arc、Yandex Browser** など Chromium 系ブラウザで動作します。

## インストール

1. [最新リリース](https://github.com/tedovy/tiktok-repost-cleaner/releases/latest)から `tiktok-repost-cleaner-*.zip` をダウンロードします。
2. 解凍します。
3. `chrome://extensions` を開きます（Edge：`edge://extensions`、Yandex：`browser://extensions`）。
4. **デベロッパー モード** をオンにします。
5. **パッケージ化されていない拡張機能を読み込む** をクリックし、解凍したフォルダを選びます。
6. 拡張機能をツールバーに固定します（パズルアイコン → ピン）。

## 使い方

1. このブラウザで TikTok にログインします。
2. 拡張機能のアイコンをクリックします。
3. **すべて** または **最新…** を選び、件数を入力します。
4. **削除** を押します。プロフィールが開き、すぐに削除が始まります。隅のパネルに進捗が表示されます。**完了** と表示されるまでタブを閉じないでください。
5. **ページを再読み込み** を押すと、更新されたリポスト一覧が表示されます。

## 速度と TikTok の制限

| モード | 同時に読む一覧ページ数 | 同時に削除する件数 |
|---|---|---|
| 慎重 | 1 | 3 |
| 標準 | 4 | 16 |
| 高速 | 8 | 48 |

削除は TikTok にとって軽い処理ですが、リポスト一覧は重く、頻繁にリクエストするとアカウント全体で一時的に制限されます（しばらくはサイトのリポストタブも空になります）。その場合、拡張機能は一時停止して再試行します。制限が解除されなければ停止し、削除できた件数を表示します。数分待ってからもう一度ボタンを押せば、残りの削除を続けます。

## 仕組み

拡張機能はサイト上でクリック操作をしません。開いている TikTok のタブから、TikTok のサイトと同じリクエストを送ります：

- `GET /api/repost/item_list/` — リポスト一覧（1 ページ 30 件）；
- `POST /tiktok/v1/upvote/delete?item_id=…` — **リポストを削除** ボタンと同じリクエスト。

TikTok 以外にはどこにも送信しません。拡張機能はデータを収集せず、パスワードや Cookie も読みません。

## 権限

- `tiktok.com` — TikTok のタブ内で動作するため；
- `scripting` — そのタブで削除を開始するため；
- `tabs` — プロフィールを開くため；
- `storage` — 設定を保存するため。

## 免責事項

TikTok および ByteDance とは無関係です。この拡張機能は TikTok の非公式なウェブ API を使用しており、仕様はいつでも変わる可能性があります。削除したリポストは自動では元に戻せません。自己責任でご利用ください。
